# Git workflow

Initialize or clone a project, review status and diff, stage individual paths, commit, and use fetch/pull/push controls. Branch, tag, stash, and provider review operations are available through the Git panel and CLI.

Conflict previews show the repository's ours and theirs blobs before resolution. Resolve explicitly with one side, then inspect status again. Git commands use argument arrays and repository paths are validated; provider API credentials must be supplied through the configured secret mechanism.
