# Visual designer

Create or select a project, choose an operator from the palette, and place it on the canvas. Connect the output handle of one node to the input handle of another, then select a node to edit its validated configuration. Save after configuration changes; topology, layout, undo, redo, and collaboration updates preserve node configuration.

Use **Validate** before generating source. Validation reports stable problem codes and identifies the affected node where possible. Generated Python and SQL are available from the source panel; supported edits can be reconciled back into the visual document. Unsupported edits remain custom-owned rather than being overwritten.
